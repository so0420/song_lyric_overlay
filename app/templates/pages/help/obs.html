OBS 오버레이 설정

OBS에 가사 오버레이를 추가하고 디자인을 커스터마이징하는 방법입니다

목차
  • OBS 브라우저 소스 추가
  • 디자인 설정
  • 프리셋
  • 토큰 관리

OBS 브라우저 소스 추가

1

오버레이 설정 페이지 접속

사이드바 메뉴에서 OBS 오버레이 설정을 클릭하거나 /overlay/settings에 접속합니다.

2

URL 복사

페이지 좌측 하단의 OBS 브라우저 소스 URL 영역에서 "클릭하여 URL 표시"를 누른 뒤 복사 버튼을 클릭합니다.

이 URL에는 고유 인증 토큰이 포함되어 있습니다. 타인에게 공유하지 마세요. URL이 노출되면 다른 사람이 오버레이를 제어할 수 있습니다.
3

OBS에서 브라우저 소스 추가

OBS Studio에서:

  1. 소스 패널에서 + 버튼 클릭
  2. 브라우저 선택
  3. 이름을 입력하고 확인
  4. URL 필드에 복사한 주소 붙여넣기
  5. 너비: 1920, 높이: 1080 입력
  6. 확인 클릭
4

위치 조정

브라우저 소스를 OBS 화면에서 원하는 위치와 크기로 배치합니다. 보통 화면 전체를 덮도록 설정하는 것이 좋습니다 (가사 위치는 오버레이 설정에서 조정).

권장 설정: 너비 1920 x 높이 1080 (Full HD). 소스를 화면 전체에 맞추면 가사 위치가 오버레이 설정과 정확히 일치합니다.

디자인 설정

가사 공통

  • 글꼴: 다양한 한국어/일본어 글꼴 중 선택 (Pretendard, Noto Sans KR, 나눔고딕, 도현, 굴림체, 궁서체, 온글잎 박다현체, 옴돋체, 강원교육모두체, 조선굴림 등)
  • 가사 크기: 현재 가사의 기본 글자 크기 (32~80px)
  • 외곽선: 텍스트 외곽선 켜기/끄기 및 색상
  • 그림자: 텍스트 그림자 효과
  • 애니메이션: 가사 전환 시 페이드 애니메이션

현재 / 이전 / 다음 가사

각 가사 유형별로 개별 스타일을 설정할 수 있습니다:

  • 색상: 텍스트 색상 (현재 가사 기본: 노란색, 이전/다음: 흰색)
  • 글자 크기: 이전/다음 가사는 현재 가사 대비 비율(30~100%)로 설정
  • 굵기: Regular ~ Black (6단계)
  • 기울임꼴: 이탤릭체 적용
  • 외곽선 두께: 각 가사별 외곽선 두께 개별 설정
  • 표시 여부: 이전/다음 가사를 끄거나 켤 수 있음

외국어 가사 줄별 설정

외국어 가사(원문/발음/해석)의 각 줄을 개별적으로 설정할 수 있습니다:

  • 표시 여부: 원문, 발음, 해석 중 필요한 줄만 선택 (최소 1개)
  • 줄별 크기 비율: 각 줄의 크기를 해당 가사 크기 대비 50~150%로 설정
  • 외국어 가사일 때 이전/다음 끄기: 여러 줄 가사 표시 시 화면이 가려지는 것을 방지

노래 정보

  • 표시 위치: 6가지 위치 (좌상단, 중앙상단, 우상단, 좌하단, 중앙하단, 우하단)
  • NOW 배지: "NOW" 태그 표시 여부
  • 제목/가수: 각각 표시 여부, 크기, 굵기, 외곽선 개별 설정

재생목록 표시

  • 표시 위치: 왼쪽 또는 오른쪽
  • 최대 표시 곡 수: 3~10곡
  • 스타일: 글자 크기, 배경 색상/투명도, 글자 색상, 현재 곡 강조 색상
  • 썸네일/가수명: 표시 여부 개별 설정

미리보기

설정 페이지 좌측에 실시간 미리보기가 표시됩니다. 설정을 변경하면 즉시 미리보기에 반영되어, 저장 전에 결과를 확인할 수 있습니다.

팁: 설정을 변경한 후 반드시 설정 저장 버튼을 눌러야 실제 OBS 오버레이에 적용됩니다.

프리셋

자주 사용하는 디자인 설정을 프리셋으로 저장하여 빠르게 전환할 수 있습니다.

  • 프리셋 저장: 현재 설정을 이름을 지정하여 저장
  • 프리셋 적용: 저장된 프리셋 이름을 클릭하여 한번에 적용
  • 프리셋 덮어쓰기: 기존 프리셋에 현재 설정을 덮어쓰기
  • 이름 변경 / 삭제: 프리셋에 마우스를 올리면 편집/삭제 버튼 표시
활용 예시: "일반 노래용", "일본어 노래용", "숏츠 녹화용" 등 상황별 프리셋을 만들어두면 편리합니다.

토큰 관리

오버레이 URL과 토큰

OBS 브라우저 소스 URL에는 고유한 인증 토큰이 포함되어 있습니다. 이 토큰으로 OBS 오버레이가 서버에 인증되어 가사를 수신합니다.

토큰 재발급

URL이 유출되었거나 보안이 걱정되면 토큰 재발급 버튼으로 새 토큰을 발급받을 수 있습니다.

토큰을 재발급하면 기존 URL은 즉시 무효화됩니다. OBS에서 새 URL로 다시 설정해야 합니다.

문제 해결

OBS에 가사가 표시되지 않아요

  • OBS 브라우저 소스의 URL이 올바른지 확인하세요.
  • 노래하기 페이지에서 곡이 재생 중인지 확인하세요.
  • OBS 오버레이 좌측 상단에 "연결 끊김" 메시지가 있다면, 서버 연결이 끊긴 것입니다. 잠시 후 자동 재연결됩니다.
  • 토큰을 재발급한 경우, 새 URL을 OBS에 다시 입력해야 합니다.

가사 싱크가 안 맞아요

  • 노래하기 페이지에서 오프셋을 조정해보세요 ([] 또는 ,. 키).
  • 가사 편집기에서 전체 오프셋을 조정할 수도 있습니다 (타임라인 상단 ◀▶ 버튼).
  • 정밀 조정이 필요하면 편집기에서 개별 구간의 시작/종료 시간을 수정하세요.

OBS 오버레이가 검은 화면이에요

  • 이것은 정상입니다. 노래가 재생되지 않을 때는 오버레이가 투명(또는 검은색)으로 표시됩니다.
  • 노래하기 페이지에서 곡을 재생하면 가사가 나타납니다.
