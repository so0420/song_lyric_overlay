가사 편집기

노래 가사를 입력하고 싱크를 맞추는 편집기의 전체 사용법입니다

전체 편집 순서

1

곡 검색 & 선택

편집기 좌측 영역에서 곡을 검색합니다. 곡 제목이나 가수명으로 검색 가능합니다.

2

MR 영상 선택

유튜브에서 MR(반주) 영상을 검색하여 연결합니다. 영상이 있어야 싱크를 맞출 수 있습니다.

3

가사 입력

가사를 입력합니다. 3가지 방법이 있습니다: 파일 가져오기, 뭉치 가사 입력, 구간 추가 버튼으로 한 줄씩 추가.

4

싱크 맞추기

실시간 싱크 모드로 영상에 맞춰 Enter 키를 눌러 박자를 맞춥니다. 이후 타임라인에서 세밀하게 조정합니다.

5

저장

가사 버전 제목을 입력하고 저장하기 버튼을 누릅니다. 로그인 없이 익명으로도 저장 가능합니다.

곡 검색 & 선택

곡 검색

편집기 좌측의 곡 검색 버튼을 누르면 검색 모달이 열립니다.

곡 제목이나 가수명으로 검색 가능합니다.

노래 등록

찾는 노래가 없으면 직접 등록할 수 있습니다. 검색 모달 하단의 커스텀 노래 추가 버튼을 눌러 노래 제목과 가수를 입력합니다. 등록된 노래는 모든 사용자가 검색할 수 있습니다.

MR 영상 연결

곡을 선택하면 자동으로 유튜브 MR 영상 검색이 실행됩니다. 검색 결과에서 원하는 MR 영상을 선택하세요.

  • 자동 검색 결과가 마음에 들지 않으면 직접 검색어를 입력하여 다시 검색할 수 있습니다.
  • 유튜브 영상 ID를 직접 입력할 수도 있습니다.
  • 무한 스크롤로 더 많은 결과를 불러올 수 있습니다.
팁: "곡 제목 + MR" 또는 "곡 제목 + instrumental"로 검색하면 반주 영상을 찾기 쉽습니다.

가사 입력 방법

1. 가사 파일 가져오기

파일 버튼으로 .txt 또는 .lrc 파일을 불러올 수 있습니다.

지원하는 파일 형식:

  • 각 줄이 [MM:SS.ss]가사텍스트 형식
  • 같은 타임스탬프의 연속 줄은 하나의 구간으로 합쳐짐 (원문/발음/해석)
  • @KEY: 같은 메타데이터 줄은 자동 무시
팁: 파일에서 가져온 가사는 시작/종료 시간이 자동으로 설정됩니다. 각 구간의 종료 시간은 다음 구간의 시작 시간으로 설정됩니다.

2. 뭉치 가사 입력

뭉치 가사 입력 버튼으로 전체 가사를 한번에 붙여넣을 수 있습니다. 두 가지 모드가 있습니다:

단일 줄 모드

  • 한 줄 = 하나의 가사 구간
  • 빈 줄은 무시됩니다
  • 한국어 가사처럼 한 줄로 된 가사에 적합

여러 줄 모드 (번역 포함)

  • 빈 줄(엔터 2번 이상)로 구간을 구분합니다
  • 구간 내 줄 수에 따라 자동 분류:
    • 1줄 = 그대로 가사 한 줄 (한국어 가사 등)
    • 2줄 = 원문 / 해석
    • 3줄 = 원문 / 발음 / 해석
  • 외국어 가사(일본어, 영어 등)에 적합
가사 정리 기능: 뭉치 입력 모달의 가사 정리 버튼을 누르면 불필요한 공백, 특수문자, 중복 줄바꿈을 자동 정리합니다. 다른 곳에서 복사해 온 가사에 이상한 문자가 섞여있을 때 유용합니다. 또한 일본어만 있는 줄(원문 줄)은 바로 위에 빈 줄이 없으면 자동으로 빈 줄을 넣어 구간을 나눠 줍니다.

3. 구간 추가 버튼

가사 구간 추가 버튼이나 Enter 키로 새 구간을 추가합니다. 선택된 가사 뒤에 삽입되며, 선택된 것이 없으면 맨 뒤에 추가됩니다.

가사 검색 (다른 사용자의 가사 복사)

상단 툴바의 가사 검색 버튼으로 다른 사용자가 공개한 가사를 검색하여 복사해올 수 있습니다. 복사한 가사는 자유롭게 수정하여 저장할 수 있습니다.

싱크 맞추기

실시간 싱크 모드

영상을 재생하면서 가사 타이밍을 맞추는 모드입니다.

1

시작

실시간 싱크 버튼을 누르면 모든 가사에 대해 싱크 모드가 시작됩니다. 영상이 자동 재생됩니다.

2

타이밍 입력

화면에 현재/다음 가사가 표시됩니다. 가사가 시작되는 순간 Enter를 누르세요. 그 시점이 해당 구간의 시작점이 됩니다.

3

종료

모든 구간을 처리하면 자동 종료됩니다. 중간에 Esc를 눌러 중단할 수도 있습니다.

범위 싱크

실시간 싱크 옆의 작은 버튼을 누르면 특정 범위만 선택하여 싱크를 맞출 수 있습니다. 이미 맞춘 부분을 건드리지 않고 일부만 다시 맞추고 싶을 때 유용합니다.

수동 시간 조정

  • 시작점 캡처 (S): 현재 영상 재생 위치를 선택된 가사의 시작 시간으로 설정
  • 종료점 캡처 (E): 현재 영상 재생 위치를 선택된 가사의 종료 시간으로 설정
  • 타임라인에서 직접 입력: 각 가사의 시작/종료 시간을 M:SS.mm 형식으로 직접 입력

전체 오프셋 조정

타임라인 상단의 ◀ ▶ 버튼으로 모든 가사의 시간을 일괄적으로 ±0.1초씩 이동할 수 있습니다. 전체적으로 싱크가 미세하게 밀려있을 때 유용합니다.

타임라인 편집

타임라인 항목

각 가사 구간은 타임라인에 하나의 항목으로 표시됩니다. 각 항목에는:

  • 드래그 핸들 (⋮⋮): 끌어서 순서 변경
  • 시작/종료 시간: 직접 편집 가능 (M:SS.mm 형식)
  • 가사 텍스트: 직접 편집 가능
  • 삭제 버튼 (×): 해당 구간 삭제

드래그 & 드롭

드래그 핸들을 잡고 위아래로 끌면 가사 순서를 변경할 수 있습니다. 순서를 바꿔도 각 위치의 시간대는 유지됩니다 (텍스트만 자리를 바꿈).

다시 정렬

다시 정렬 버튼을 누르면 모든 가사가 시작 시간 기준으로 오름차순 정렬됩니다.

저장 & 자동 저장

수동 저장

  • 상단 툴바의 저장하기 버튼 또는 Ctrl+S
  • 저장 전 가사 버전 제목(예: "정식 싱크", "숏츠용" 등)을 입력해야 합니다
  • 로그인하지 않아도 익명으로 저장 가능합니다
  • 같은 곡에 여러 버전의 가사를 저장할 수 있습니다

자동 저장 (브라우저)

편집 내용은 2.5초 간격으로 브라우저(localStorage)에 자동 저장됩니다. 실수로 페이지를 닫아도 다시 열면 복구 여부를 물어봅니다.

자동 저장은 브라우저 내부에만 저장됩니다. 다른 브라우저나 기기에서는 복구할 수 없으므로, 중요한 작업은 반드시 저장하기 버튼으로 서버에 저장하세요.

Undo / Redo

Ctrl+Z로 실행 취소, Ctrl+Shift+Z로 다시 실행할 수 있습니다. 최대 50단계까지 지원합니다. 가사 추가, 삭제, 시간 변경, 텍스트 편집, 순서 변경, 뭉치 입력 등 모든 작업이 Undo 대상입니다.

단축키

Space재생 / 일시정지
J 또는 ←-5초 이동
L 또는 →+5초 이동
S선택된 가사의 시작점을 현재 재생 위치로 설정
E선택된 가사의 종료점을 현재 재생 위치로 설정
Enter새 구간 추가 (텍스트 입력 중) / 싱크 진행 (싱크 모드)
Ctrl+Z실행 취소
Ctrl+Shift+Z다시 실행
Ctrl+S즉시 저장
Esc싱크 모드 종료 / 모달 닫기
참고: Space, J, L, S, E는 텍스트 입력 필드에 포커스가 없을 때만 작동합니다.
