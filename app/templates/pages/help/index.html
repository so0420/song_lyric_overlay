서비스 소개

Jamku Song은 방송 중 노래 가사를 OBS 오버레이로 표시하는 서비스입니다.
노래를 검색하고, 가사를 싱크에 맞춰 편집한 뒤, OBS 브라우저 소스를 통해 시청자에게 실시간으로 가사를 보여줄 수 있습니다.

기본 흐름: 가사 편집 → 노래하기 페이지에서 재생 → OBS 오버레이에 실시간 표시

가사 편집기

가사 편집 순서

1

곡 검색 & 선택

편집기에서 노래를 검색하여 선택합니다. iTunes 음원 또는 커스텀 노래를 등록할 수 있습니다.

2

MR 영상 선택

유튜브에서 MR(반주) 영상을 검색하여 연결합니다.

3

가사 입력

뭉치 가사 입력으로 전체 가사를 한번에 붙여넣거나, 구간 추가 버튼으로 한 줄씩 추가합니다.

4

싱크 맞추기

실시간 싱크 모드를 사용하면 영상을 재생하면서 Enter 키로 박자를 맞출 수 있습니다. 이후 타임라인에서 세밀하게 조정합니다.

5

저장

가사 버전 제목을 입력하고 저장합니다. 로그인하지 않아도 익명으로 저장 가능합니다.

뭉치 가사 입력 모드

  • 단일 줄 모드: 한 줄이 하나의 가사 구간이 됩니다.
  • 여러 줄 모드: 빈 줄(엔터 2번)로 구간을 나눕니다.
    • 1줄 = 그대로 가사 한 줄
    • 2줄 = 원문 / 해석
    • 3줄 = 원문 / 발음 / 해석

편리한 기능

  • Undo/Redo: Ctrl+Z / Ctrl+Shift+Z로 실행 취소/다시 실행
  • 자동 저장: 편집 내용이 브라우저에 자동 저장되어 페이지를 닫아도 복구 가능
  • 모양 정리: 가사의 불필요한 공백, 특수문자, 중복 줄바꿈을 한번에 정리
  • 드래그 & 드롭: 타임라인에서 가사 순서를 드래그로 변경
  • 오프셋 조정: 전체 가사의 시작/종료 시간을 일괄 조정

노래하기

사용 방법

  1. 노래하기 페이지에서 노래를 검색합니다.
  2. 검색 결과에서 원하는 가사 버전을 선택하면 재생목록에 추가됩니다.
  3. Space로 재생하면 MR이 재생되며, 가사가 OBS 오버레이에 실시간으로 표시됩니다.
  4. 재생목록에 여러 곡을 추가하여 연속 재생할 수 있습니다.

오프셋 조정

싱크가 미세하게 맞지 않을 때 로컬 오프셋과 OBS 오프셋을 조정할 수 있습니다.

  • 로컬 오프셋: 노래하기 화면에 표시되는 가사 타이밍 조정
  • OBS 오프셋: OBS 오버레이에 표시되는 가사 타이밍 조정

OBS 오버레이 설정

OBS에 오버레이 추가하기

1

오버레이 설정 페이지 접속

메뉴에서 OBS 오버레이 설정으로 이동합니다.

2

URL 복사

하단의 OBS 브라우저 소스 URL을 복사합니다. 이 URL에는 고유 토큰이 포함되어 있으므로 타인에게 공유하지 마세요.

3

OBS 브라우저 소스 추가

OBS에서 소스 추가 → 브라우저를 선택하고, URL에 복사한 주소를 붙여넣습니다. 권장 크기: 1920x1080

오버레이 디자인 설정

설정 카테고리

  • 가사 공통: 글꼴, 가사 크기, 외곽선, 그림자, 애니메이션
  • 현재 가사: 색상, 굵기, 기울임꼴, 외곽선 두께
  • 이전/다음 가사: 표시 여부, 글자 크기 비율, 색상, 굵기, 기울임꼴, 외곽선 두께
  • 가사 표시: 외국어 가사 줄 표시 (원문/발음/해석), 줄별 크기 비율
  • 노래 정보: 제목/가수/NOW 배지 표시 위치 및 스타일
  • 재생목록: 표시 여부, 위치, 글자 크기, 배경 색상

프리셋

현재 설정을 프리셋으로 저장해두면 언제든 불러올 수 있습니다. 상황에 따라 여러 프리셋을 만들어 활용하세요.
