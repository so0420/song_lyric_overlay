노래책 관리

공개 페이지 보기

공개 주소

시청자에게 공유할 노래책 페이지 주소예요. (2~30자, 소문자 영문/숫자/한글/_/- 만 가능)

소개

노래책 상단에 표시될 소개 문구예요. (최대 1000자)

노래 태그

곡을 분류할 태그(카테고리)를 만들어요. 곡 추가/수정 시 선택할 수 있어요. (최대 30개)

소셜 링크

노래책 페이지에 표시될 외부 링크예요. (최대 10개)

노래 신청

신청 받기
노래 신청 기능 전체를 켜고 끕니다.
웹 신청 허용
공개 노래책 페이지에서 시청자가 직접 신청할 수 있어요.
신청 곡 재생목록 자동 추가
신청이 들어오면 노래하기 페이지 재생목록에 자동으로 올라갑니다(가사 또는 MR이 연결된 곡만).

치지직 연동

치지직 계정을 연동하면 시청자가 채팅/후원에 !신청 노래제목 으로 곡을 신청할 수 있어요.
