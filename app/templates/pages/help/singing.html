노래하기

노래를 재생하고 OBS 오버레이에 가사를 실시간으로 표시하는 방법입니다

접근 권한

노래하기 기능은 승인된 사용자만 이용할 수 있습니다.

1

회원 가입 & 로그인

이메일로 가입하거나 Google/Naver 소셜 로그인을 이용합니다.

2

사용 요청

노래하기 페이지에 접근하면 사용 요청 양식이 표시됩니다. 방송 플랫폼 주소를 입력하고 요청을 보냅니다.

3

승인 대기

관리자가 요청을 검토한 후 승인하면 노래하기 기능을 사용할 수 있습니다. 자동 승인이 켜져 있으면 즉시 승인됩니다.

곡 검색 & 추가

곡 검색

상단 검색창에 노래 제목, 가수명, 또는 가사 버전 제목을 입력하면 검색 결과가 나타납니다.

곡 제목이나 가수명으로 검색 가능합니다.

가사 선택 & 재생목록 추가

검색 결과에서 노래를 클릭하면 해당 곡에 등록된 가사 버전 목록이 표시됩니다. 원하는 버전을 선택하면 재생목록에 추가됩니다.

팁: 같은 곡이라도 여러 사람이 만든 다양한 가사 버전이 있을 수 있습니다. 작성자와 제목을 확인하고 선택하세요.

노래 직접 등록

찾는 노래가 없으면 검색 결과 하단의 커스텀 노래 추가 버튼으로 직접 등록할 수 있습니다.

재생목록 관리

재생목록 & 즐겨찾기 탭

  • 재생목록: 현재 세션에서 추가한 곡 목록. 순서대로 재생됩니다.
  • 즐겨찾기: 하트를 눌러 저장해둔 곡 목록. 즐겨찾기에서 클릭하면 재생목록에 추가됩니다.

재생목록 조작

  • 곡 클릭: 해당 곡으로 즉시 이동하여 재생
  • 삭제 버튼: 재생목록에서 곡 제거
  • 재생목록 비우기: 전체 재생목록 초기화
  • 자동 삭제: 토글을 켜면 재생이 끝난 곡이 자동으로 제거됩니다

OBS 재생목록 표시

오버레이 설정에서 재생목록 표시를 켜면, OBS 화면에도 재생목록이 표시됩니다. 현재 재생 중인 곡이 강조되어 시청자가 곡 목록을 볼 수 있습니다.

재생 & 가사 표시

재생 방법

  • 재생목록에서 곡을 클릭하거나, Space 키를 눌러 재생/일시정지합니다.
  • 곡이 끝나면 자동으로 다음 곡으로 넘어갑니다.
  • ← / → 키로 이전/다음 곡으로 이동합니다.

가사 동기화

노래하기 페이지에서 곡을 재생하면 WebSocket을 통해 OBS 오버레이에 가사가 실시간으로 전송됩니다.

  • 노래하기 화면: 현재 가사가 화면 하단에 표시됩니다.
  • OBS 오버레이: 동일한 가사가 오버레이 설정에 따라 스타일링되어 표시됩니다.
참고: 연결이 끊어지면 3초마다 자동으로 재연결을 시도합니다. OBS 오버레이도 마찬가지로 자동 재연결됩니다.

오프셋 조정

가사 싱크가 미세하게 맞지 않을 때, 가사 전체의 표시 타이밍을 실시간으로 조정할 수 있습니다.

  • 로컬 오프셋: 노래하기 화면에서 보이는 가사 타이밍을 조정합니다. [ / ] 키로 ±100ms, Shift와 함께 누르면 ±500ms.
  • OBS 오프셋: OBS 오버레이에 전송되는 가사 타이밍을 조정합니다. , / . 키로 ±100ms, Shift와 함께 누르면 ±500ms.
  • 초기화: Shift+0으로 모든 오프셋을 0으로 리셋합니다.
팁: 보통은 OBS 오프셋만 조정하면 됩니다. 노래하기 화면과 OBS 오버레이의 타이밍이 서로 다를 때만 각각 따로 조정하세요.
